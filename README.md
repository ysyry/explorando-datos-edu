# Explorando datos 📊

App educativa para aprender a **pensar consultas sobre datos**, pensada para 4to año
(Educación Informática, secundaria con orientación en turismo — Villa La Angostura, Neuquén).

Guía a los alumnos paso a paso: de una **pregunta en castellano** → elegir el **verbo**
(filtrar, contar, ordenar, agrupar, graficar) → armar las **piezas** → **ejecutar** la
consulta sobre un CSV real → **interpretar** el resultado. Misma lógica que Pandalyze/Pandas,
pero sin backend.

## Cómo se usa

- Es un único `index.html`, todo corre en el navegador (no necesita servidor ni internet
  más allá de abrir la página). Subís un CSV propio o usás el dataset de ejemplo.
- **En vivo:** https://ysyry.github.io/explorando-datos-edu/

## Datasets

Acepta cualquier CSV. Para biodiversidad del Nahuel Huapi (nativas vs exóticas, especies
introducidas en Isla Victoria) ver el proyecto de planificación asociado.
